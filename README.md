# Student Performance Analysis

This project analyzes student performance data using Python and data analytics techniques.

## Overview
The project focuses on analyzing student-related factors such as study time, absences, and academic behavior to identify patterns and generate useful insights.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Features
- Dataset loading and preprocessing
- Study time analysis
- Absence analysis
- Data visualization using graphs
- Trend identification

## Visualizations
- Bar Graph: Average Study Time vs Absences
- Scatter Plot: Study Time vs Absences

## Outcome
Generated insights from student datasets and visualized relationships between study habits and attendance using Python-based analytics techniques.

## Files Included
- `student_analysis.ipynb`
- `student.csv.csv`
